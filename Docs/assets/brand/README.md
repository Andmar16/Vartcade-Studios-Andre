# brand

## Silong Shelters (checklist A20)
A made-up shelter company that appears on the menu billboard, lobby posters,
bunker signs and loading screens, so every scene feels like the same world.
*Silong* is the space under a Filipino house.

- **Mascot:** a happy sun in rubber hose cartoon style (1920s-30s: bendy limbs,
  pie-cut eyes, white gloves). An original character, not based on any existing one.
  The joke: a grinning sun sells shelters in a game about the sun going down.
- **Deliverables:** logo, mascot in 2 poses (waving, thumbs up), 3 posters with
  Taglish slogans.
- **Could:** the mascot sinks lower and sweats on posters as the Days pass (A18).
- **Limits:** PG, no real brands or logos anywhere in the game.
