How to read a board
1
Gold number on the screen = a note with the same number on the right.
Each note says what the element is, what it does, and the script that owns it, its priority (Must / Should / Could, same as the checklist) and its motion.
The strip under each screen covers states, animation and phone vs PC.
Dashed red boxes are assumptions waiting on the open questions (D-Q1 to D-Q8).

References and what we take from each
60 Seconds!
Dark-humor doomsday tone; scrappy hand-drawn UI; items as illustrated objects; a ticking countdown that raises tension.
Sally Face
Exaggerated faces, thick outlines, muted grim palette with sickly warm light; eerie but cute.
Fallout Shelter
Vault-suit look with numbered jumpsuits (our seat numbers); cutaway rooms; cheerful puppets in a bleak world.
Fran Bow
Surreal, slightly unsettling backgrounds: crooked shapes, dead trees, flat painted layers, odd drifting details.
Kitty Powers' Matchmaker
Cutout puppet animation: parts rotate on pivots, quick expression swaps, bouncy reactions.
UNO (digital)
Fanned hand at the bottom, hover lifts a card and shows what it does, clear table center.
Buckshot Roulette
Seated first-person view across a tilted table; close, tense camera; opponents framed by a single lamp.
