States, motion and platform
States
Seat: empty, joining (spinner), not ready, ready, bot, disconnected (greyed, 'Reconnecting'). Start button: disabled (reason shown) or enabled (pulses gently once).
Motion
A puppet pops into its seat when a player joins (scale 0.8 to 1 with a small bounce) and waves. Ready: puppet gives a thumbs up; seat border turns gold.
Phone vs PC
Phone: seats in one row of 6 small cards; join code and Start stay large. PC: same layout, more space between seats.
Edge cases
Host leaves: room closes, everyone returns to menu with a message. Wrong code: shake the field, 'No game with that code'.
Notes for developers

Join code
6 characters, grouped 3 + 3, no look-alike letters (no O/0, I/1). Copy button copies it and shows 'Copied' for 2 s. Joiners type it on the menu modal.
